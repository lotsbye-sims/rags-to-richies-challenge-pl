# Od zera do milionera

Starter wyzwania Rags to Riches do The Sims 4. Jeden Sim, pusta działka i §0. Narzędzie losuje Sima (cechy, aspirację, karierę i sposób dorabiania), świat i działkę, kilka utrudnień na start oraz cel, który kończy wyzwanie.

Obok jest karta zasad: lista kroków przygotowania do odhaczania, zasady, które obowiązują zawsze, i zasady domowe, które włączasz lub wyłączasz według własnych upodobań.

## Jak używać

Całe narzędzie to jeden plik `index.html`. Nie trzeba nic instalować ani uruchamiać serwera. Wystarczy otworzyć plik w przeglądarce albo włączyć GitHub Pages w ustawieniach repozytorium.

W panelu „Moje dodatki” odznacz dodatki, których nie masz. Przeglądarka zapamiętuje wybór, ostatnie wyzwanie i odhaczone kroki.

## Jak dopisać własne dane

Imiona, cechy, kariery, utrudnienia, cele i zasady są zwykłymi listami na początku skryptu w `index.html`. Żeby coś dodać albo zmienić, edytuj odpowiednią listę.

Nazwy cech, aspiracji, karier, światów i dodatków są po angielsku, tak jak w angielskiej wersji gry.
